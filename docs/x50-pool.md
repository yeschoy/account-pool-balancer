# 50X 推理号池

## 能力与边界

50X 现在具有通用概览、账号、客户端/导入Key、路由、错误/重试规则、请求/错误/详情日志页面；保留独立注册机与注册设置。`provider=x50`，保留分组 `x50`，`sk-50x-` Key 不属于 OpenDesign，也不允许显式导入其他池。

- 原生 `GET /v1/models`、`POST /v1/chat/completions`（JSON / SSE、工具调用）。保留原始模型名、工具与大整数；其他协议/子路径本地拒绝，不转换。
- 默认测试模型 `deepseek-ai/DeepSeek-V4.1-Flash-1017`，可手填模型。目录仅是发现，不证明推理授权。真实测试是收费上游动作，界面提示；本轮仅使用本地 mock，未发生产付费请求。
- `x50` 配置块独立保存 Routing / Quota / ModelSyncSec / Pricing / RequestLog / ErrorLog / DetailLog。路由含粘性/会话头/TTL/忙时、账号并发/RPM与等待、尝试上限、健康、超时/体积/缓存/连接数；账号权重/优先级沿用共同调度器。缺省配置使用不可变50X基线，不继承别池。价格默认未知，可手填估算价。
- 错误规则支持现有状态/正文/响应头匹配、account/model范围、动作/冷却/恢复/刷新/下游状态、增删改/排序/启停。重试规则沿用现有“命中停止”契约，停用/删除停止规则后可按错误动作与尝试预算换号；不添加伪“强制重试”开关。未知发送结果/已输出或截断流不能绕过安全门重放。
- 请求/错误摘要默认开启，可分别关闭；详情默认关闭（独立于全局 detail，每体最多 min(共享上限,64KiB)）。日志保留/总容量全局共享、只读明确标注，保存50X不修改它们。认证凭据、管理Token、代理、会话身份脱敏。关闭采集不删除历史，不影响错误规则执行。

## 真实余额

账号 `ControlKey` 是可选的裸管理会话 Token（不是密码、Cookie 或推理 Key）；GET `{推理Base的origin}/api/billing` 使用 `Authorization: Token <session>`。推理与目录仅用 `Bearer <sk-50x-Key>`，不会发送管理Token到 OpenDesign 控制面。

`balance_usd` 必须是有限十进制字符串或 JSON 数字；缺失/null/布尔/对象/非有限/格式错误都失败而不是0。快照 `quota.x50` 保存余额、tier、成功时间和最近错误；目录独立保存时间/错误。失败保留同来源的历史，UI明确历史/失效；会话失效不等同推理Key失效。来源绑定完整provider/key/session/base/proxy哈希，锁内发布复核；换源或删除期间晚返回不能污染新来源，metadata重启亦核对。

周期余额读受独立 Quota.enabled/interval/concurrency 控制；目录额外受 ModelSyncSec 控制，0关闭周期目录HTTP（首次和手动仍可读），手动刷新始终强制检测。付费/预付费层且新鲜余额≤0时暂停调度；旧免费层 daily allowance 未接入，不能拿钱包0猜测耗尽。未知/过期不伪造金额、重置时间或免费配额。

**同一上游账号多Key共享余额、免费配额和限流，不按Key累加成总可用额度。** 未获得稳定账号/共享付费身份的读取契约，因此没有“跨Key汇总额度”或funding作用域。不会自动创建付费方案、充值或购买。

## 注册机批量入池

1. 勾选已完成且有Key的候选，可全选当前可见的已完成候选。
2. 点击“所选批量入池”，确认只导入50X；按项报告新增、已存在及失败。
3. 初次复制Key/管理会话/邮箱和原注册代理到推理账号；不复制密码或接码凭据，不搬移/破坏注册历史。
4. 以 config.Store.Update 完成校验和原子磁盘替换为成功边界。重复Key幂等，保留用户已经修改的推理代理/策略。非法候选单独报告；整体磁盘失败不误报成功。
5. `inPool/poolAccountId` 根据当前真实持久化配置关联推导，不维护会漂移的双写布尔值。默认隐藏已入池；勾选“已入池”后连同待入池项一起显示，并标记。停用目标仍算已入池；删除目标或改走原Key后，候选重新默认可见，可以再次导入；候选删除不会删除推理账号。

接口：`POST /api/x50/pool/import {ids:[...]}`（1–500项）。已入池关联由 `GET /api/x50/candidates` 返回，摘要不返回明文Key，显式读取边界保持原有 `/key`。

## 批量推理代理

账号页“批量重置50X推理代理”弹窗明确选择：所选50X账号，或池内全部50X账号（包含停用）；直连或指定URL。必须点击“确认修改50X”。

接口：`POST /api/x50/pool/proxy {scope:"all"|"selected",ids:[],proxyUrl:"",confirm:"x50"}`。空字符串明确直连，不使用环境代理；所选包含不存在/外池ID、非法代理、缺作用域/确认则原子拒绝。只改50X推理账号，完全不写注册机存储或其他厂商账号。换代理使旧来源快照失效，需重新刷新。指定代理失败不偷偷转直连。
