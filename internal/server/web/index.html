TokenHarbor 账号池

这个池怎么用

Token Harbor 是 OpenAI 兼容网关（https://tokenharbor.ai/v1），账号凭证就是注册机在建号时生成的 thk_live_… Key。API 按出口地区鉴权：中国大陆直连返回 403 region_blocked，所以每个账号都要配代理，最好一个号一个出口。

免费模型（…:free）每个账号每天刷新额度；付费模型按 token 计费，余额不足时返回 402。

关于指纹与封号

  • 注册全程是纯 HTTP，不启动浏览器：没有 canvas/WebGL/字体枚举这类被动指纹，服务端看到的只有 UA、时区和出口 IP。
  • 同一代理上的多个账号会被按 IP 聚合，所以默认按号轮流分配代理，一个出口只放一个号。
  • Turnstile 由 captcha-run 代解，token 约 2 分钟有效，解完立刻提交。
  • 同一邮箱不要重复注册：服务端会把新 Key 判定为 invalid_api_key。
