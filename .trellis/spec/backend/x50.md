# 50X号池合同

适用于config/quota/pool/rules/server/web的50X接线；完整使用说明与本轮证据在 `docs/x50-pool.md`。

- ProviderX50=x50，sk-50x优先识别且不得显式归其他池；保留x50组，client/import Key及目录严格分池。
- Config.X50独立Routing/Quota/Pricing/目录刷新/请求、错误、详情开关，缺省不可继承其他池。共享日志保留/容量只读标注；本池保存不得修改共享或其他池。空规则是真正清空。
- 原生Chat/SSE/工具和models有当前公开证据，其他协议本地拒绝。X50DefaultModel精确为deepseek-ai/DeepSeek-V4.1-Flash-1017，支持手填。NativeChatOnly共享转发/脱敏/重放保护，不共享405组织暂停语义、凭据、余额或付费来源。
- 管理ControlKey为裸Token，GET origin/api/billing用Token；推理Key仅Bearer。billing强类型有限balance_usd，失败/缺字段不是零。Snapshot.X50保留历史/tier/at/error，与独立目录来源一起持久化。来源哈希包括session/key/base/proxy/provider，锁内校验晚返回，重启投影也校验。
- 新账号免费赠金没有保证；旧免费层daily allowance尚无可用接口证据，不以balance0判免费配额耗尽。仅paid/prepaid且新鲜余额≤0暂停。多Key共享账号余额/额度/限流，不按Key求和，不猜稳定付费身份，不自动充值。
- 注册入池标志必须派生自真实成功写盘的当前账号Key关联；停用仍算入池，删除目标后恢复默认可见可再入池。重复导入不覆盖用户推理代理/策略；候选非法项部分报告、整体磁盘失败不误标。
- /api/x50/pool/proxy只改50X推理账号，显式all/selected/confirm=x50，空proxyUrl是直连，混池/无效项原子拒绝；不改注册代理、密码、会话或历史。直连Transport.Proxy=nil，不借环境代理；指定代理失败不回退。
- 注册日志沿用Deploy右下角dock交互，但独立DOM/计数/轮询；停轮询递增加载序号阻止晚返回。startPolling不能调用会失效首屏请求的stopPolling（仅重置旧timer）；离页才取消待发布UI结果。注册日志/错误必须脱敏，显式Key读取保留管理员边界。
