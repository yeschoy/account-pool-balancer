# Token Harbor 注册会话与支付链接

## 需求
- 从最新默认主分支创建独立 Orca 工作区（远端为 master，不存在 main）。
- 注册机支持用户给出的 `邮箱----接码页` 输入，仍兼容三段格式。
- 已注册即保存会话，创建 Key 后立即保存，后续失败不得丢失或自动重新注册。
- 用户后续明确：只处理已注册的第一个账号，其他四个不得注册；只获取 `https://tokenharbor.ai/pricing` 的 Agent Pass 月度单次订阅链接，不做余额充值或其他套餐。绝不提交付款，不开启自动续费。
- 已验证账号通过现有接口加入远程 OVH Token Harbor 池，不覆盖线上配置；保存对应会话与密钥。
- 凭证、邮箱 token、代理密码、支付会话 URL 不进日志/Git；持久化沿用加密 signup store。

## 验收与设计
- 先确认官网当前支付交互/请求契约，拒绝猜测私有接口。先 preview 检查 Free / Agent Pass / monthly / oneTime 报价，仅该场景发送匹配报价的托管收银台创建请求；非 Free 或升级报价硬停止。支付请求不自动重试、不跟随凭证重定向；成功链接加密保存。
- 后端提供显式管理员获取链接操作，前端提供入口；链接不出现在周期轮询和实时日志中。
- 注册流程提供逐阶段持久化回调；恢复操作使用已存会话而非重复注册。
- 本地 mock 覆盖链接校验、上游错误、状态恢复、凭证投影、两段输入和已有三段输入。
- gofmt、Go tests/race/vet/build、JS syntax + 本地浏览器验收。
- 真实测试遇到验证码/注册限制应停止并报告，不绕过挑战或轮换出口规避限制；不主动消费验证码服务。
- 远程仅增量导入，导入前备份并去重；未验证的不作为可用账号入池。当前唯一账号邮箱已验证但未付款，入池后暂不启用调度，不发起付费推理。
